# Attribution

This project includes a browser-compatible JavaScript implementation of **SAM — Software Automatic Mouth**, exposed as `SamJs`.

SAM is a retro formant speech synthesizer originally created for 8-bit computers. Review the `sam.js` source and the upstream SAM.js project terms before redistribution or commercial use.

The interface, custom-preset storage, transliteration, Web Audio effects and WAV export in this archive are separate demonstration code.
